# 迷你帝國 Mini Empire

一款自動戰鬥的種族塔防網頁遊戲（3D）。王國瀕臨滅亡，老國王戰死在王城門前——身為王子，你要在六角形的世界地圖上一塊一塊奪回被不死族、哥布林、獸人與叛軍佔領的領地，最後打倒魔王、光復王城。每場戰鬥都在九宮格領地上蓋建築、讓軍隊自動迎敵。

**▶ 線上遊玩：https://easylive1989.github.io/mini_empire/**（建議使用桌機瀏覽器）

## 戰役：王子的復國之戰

1. **標題畫面**：開始遊戲（有存檔時可繼續）、無盡挑戰（收復王城後解鎖）、離開。
2. **選擇種族**：王子帶領的子民決定整場戰役的兵種與建築；接著播放約一分鐘的開場動畫（可跳過），故事會依種族改變王國、國王與王子的名字。
3. **世界地圖**：19 塊六角形領地。王子從左下角的曙光堡出發，只能進攻與已收復領地相鄰的格子；魔王坐鎮右上角的淪陷王城。
4. **收復領地**：每塊領地都是獨立的一場戰鬥——全新的九宮格、主堡從 Lv.1 開始、帶著依距離決定的戰爭資金。擊退 6 波敵軍（最後一波是首領）就能收復；王城則是 10 波混合大軍與多階段的魔王。失敗可以重新挑戰。
5. **越打越強**：每塊收復的領地都會給予永久加成（起始金幣、主堡生命、射程、傷害、出兵速度……）或解鎖特殊建築（傭兵營、哥布林火箭塔、獸人鬥技場、深層金礦、聖泉祭壇、先王紀念碑，之後每場戰鬥都能蓋一座）。可以直取王城（4 場戰鬥、加成最少、最艱難），也可以先收復更多領地累積力量。
6. **地形與敵軍**：平原、城鎮、森林、丘陵、沼澤、山口、荒原、礦脈、墓園、聖地、河谷各有戰鬥效果，戰場的景色與敵營也會跟著改變。四大勢力各有特色——哥布林小偷會偷金幣、巨魔會再生；獸人薩滿的戰吼強化整群獸人、軍閥會狂暴；叛軍弓弩配合騎士衝鋒；不死族擅長召喚。
7. **結局**：奪回王城後播放結局動畫並解鎖無盡挑戰；之後還可以繼續收復剩下的領地，全部收復可得到「統一大陸的王」稱號。

進度會自動存在瀏覽器（localStorage）。背景音樂與音效都是即時合成的，可分別開關。

**效能模式**（音樂、音效旁的儀表按鈕）：關閉反鋸齒、以 1 倍解析度渲染、改用較省的陰影並每兩幀更新一次、減少地圖上的瘴氣，換取在內建顯示晶片（Intel UHD 等）上順暢執行。第一次開啟時會依顯示晶片自動決定；若畫面持續低於約 40 fps，也會自動切換。手動切換後就照玩家的選擇。

## 怎麼玩（每場戰鬥）

1. **種族**：人類、精靈、矮人、惡魔、天使，各有專屬兵種、建築與種族特性。
2. **準備階段（不限時）**：點選空地建造建築、點選建築升級或拆除、點選主堡升級或修復、擴張土地。
3. **開戰**：按「開始第 N 波」或空白鍵。戰鬥完全自動，可切換 1x / 2x / 4x 速度。
4. **結算**：每波結束後獲得主堡稅收、資源建築產出與擊殺獎勵（無盡挑戰每 5 波還可從三個祝福中選一個）。

### 規則重點

| 項目 | 說明 |
| --- | --- |
| 領地 | 從 3×3 開始，中間是主堡；花金幣擴張相鄰土地，最大 5×5，可擴張數量由主堡等級決定 |
| 主堡 | 共 5 級，決定能蓋哪些建築、建築能升到幾級、能擴張多少土地；主堡被打爆就輸 |
| 建築 | 資源建築（產金）、兵營（戰鬥中自動出兵）、防禦塔（自動攻擊）；皆可升到 3 級 |
| 位置 | 敵人永遠從右下方來，最靠近前線的建築最先被攻擊；相鄰的同類建築有加成 |
| 損傷 | 被摧毀的建築當波停擺，戰後自動修復；主堡的損傷會保留，需要花金幣修復 |
| 兵力 | 兵營在戰鬥中依出兵速度持續出兵（有上限），每波結束後士兵解散 |
| 推進 | 士兵集結成隊後推進到中場迎敵，不利時撤回。騎士、狂魔戰士、小鬼、森林哨兵等衝鋒型兵種會走在隊伍最前面 |
| 勝負 | 戰役：擊退領地的全部敵軍即收復；無盡挑戰：撐過 30 波（第 10、20、30 波有首領）即勝利，之後可繼續無盡模式 |

### 快捷鍵

- `空白鍵`：開始下一波
- `1` `2` `3`：戰鬥速度 1x / 2x / 4x
- `U`：升級選取的建築或主堡
- `Esc`：取消選取

| 種族 | 定位 | 招牌協同 |
| --- | --- | --- |
| 人類 | 均衡＋經濟，兵種越多元越強（聯合兵種） | 長槍兵擋線＋十字弓手集火；騎士衝鋒暈眩製造破綻 |

## 開發

需要 Node.js 22。

```bash
npm install
npm run dev        # 開發伺服器 http://localhost:5173
npm test           # 單元測試（遊戲規則與戰鬥協同）
npm run build      # 型別檢查＋打包到 dist/
npm run balance    # 無頭平衡模擬：bot 依序使用五個種族遊玩無盡挑戰
npm run campaign-sim            # 戰役平衡：bot 以「直取王城」「全部收復」「只蓋 1 級兵營」三種策略遊玩
npx vite-node tools/margin.ts   # 量測各波次的防守安全邊際
```

### 專案結構

```
src/game/      純 TypeScript 遊戲邏輯（不依賴畫面，可無頭模擬）
  data/        種族、兵種、建築、怪物、敵對勢力、特殊建築、波次、祝福資料
  campaign/    戰役：世界地圖、地形、永久加成、勢力波次、劇本、存檔
  state.ts     經濟：建造、升級、擴張、修復、收入、相鄰加成
  battle.ts    戰鬥模擬（固定 30Hz tick、可重播的亂數）
  bot.ts       平衡測試用的自動玩家
src/render/    Three.js 3D 畫面：戰場（正交攝影機）、六角世界地圖與過場動畫（透視攝影機）
src/ui/        HTML 介面
src/audio/     Web Audio 即時合成的音效與背景音樂
tools/         素材處理與平衡工具
public/assets/ 已處理好的 3D 素材（meshopt 壓縮 GLB）
```

### 3D 素材

角色、建築與場景素材來自 Kay Lousberg 的 [KayKit](https://kaylousberg.com) 系列（CC0 授權，可自由使用）：Medieval Hexagon Pack、Character Pack: Adventurers、Character Pack: Skeletons、Dungeon Remastered、Halloween Bits。

`public/assets/` 已包含處理後的檔案。若要重新產生：

```bash
tools/fetch-assets.sh /tmp/kaykit          # 從 GitHub 下載原始素材包
node tools/build-assets.mjs /tmp/kaykit    # 篩選、合併、壓縮成遊戲使用的 GLB
```

建築只保留藍色版本，執行時再依種族重新上色調色盤貼圖；所有角色共用同一套骨架與動畫庫，種族差異（換色、體型、翅膀、角、光環、鬍子等配件）由程式產生。

## 部署到 GitHub Pages

`.github/workflows/deploy.yml` 會在推送到 `master` 時自動測試、打包並部署。第一次使用前，請到 repo 的 **Settings → Pages**，把 **Source** 設為 **GitHub Actions**。
